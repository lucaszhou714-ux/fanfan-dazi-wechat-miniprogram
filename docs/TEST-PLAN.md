# v0.1 测试与验收计划

## 自动检查

在项目根目录运行：

```powershell
node tests/validate.js
node tests/cloud-sync.integration.js
powershell -NoProfile -ExecutionPolicy Bypass -File tests/validate-project.ps1
```

检查范围：工程页面完整性、JSON有效性、WXML基本平衡、菜品种子数量、云端接口完整性、JavaScript语法，以及双账号邀请、加入、共同抽取、状态同步和解绑的服务器仿真。

## 单机功能用例

| 编号 | 场景 | 期望结果 |
|---|---|---|
| M01 | 设置未来7天计划 | 返回首页后今天计划正确，重启后不丢失 |
| M02 | 选择菜系和预算抽取 | 结果满足筛选条件 |
| M03 | 重复抽取 | 每次生成抽取记录，无界面卡死 |
| M04 | 点击“就吃这个” | 自动生成当天饮食日志 |
| M05 | 设置1至5星满意度 | 日志立即更新，重启后保留 |
| M06 | 删除日志 | 二次确认后删除 |
| M07 | 抽菜单签和情侣奖励 | 正常展示结果 |
| M08 | 修改昵称、预算、忌口 | 保存后重新进入仍保留 |

## 双机云端用例

| 编号 | 场景 | 期望结果 |
|---|---|---|
| C01 | A生成邀请码，B输入 | 两端进入同一情侣空间 |
| C02 | 重复使用邀请码 | 第二次加入被拒绝 |
| C03 | 使用过期邀请码 | 显示无效或过期 |

| C08 | 非成员读取集合 | 数据库权限拒绝客户端直接访问 |
