# 饭饭搭子 v0.1 产品需求文档

## 产品目标

面向一对情侣，解决工作日午餐提醒与选择困难，通过共同抽取、饮食日记和每周奖励形成轻量陪伴闭环。

## MVP用户故事

1. 用户可以设置未来七天带饭、外卖、不确定或休息计划。
2. 用户可以按菜系和预算抽取具体菜品，并确认最终选择。
3. 确认菜品后系统自动生成饮食日志，用户可以补充满意度。
4. 用户可以用24小时一次性邀请码与伴侣绑定，并共享双方主动产生的数据。
5. 用户可以选择“帮TA抽”，结果进入情侣空间并在另一端显示。
6. 用户可以查看近七天记录、外卖次数和常吃菜系。
7. 用户可以抽取本周菜单主题和情侣奖励。

## 本期不做

外卖平台实时数据、支付、广告、AI健康诊断、文档转换、多人关系、复杂后台。

## 验收标准

- 微信开发者工具可以无构建步骤直接导入。
- 首页、计划、抽菜、日记、情侣空间和设置页面可以正常进入。
- 抽取结果可确认并持久化为日志。
- 退出并重新进入后本地数据仍存在。
- 部署云函数后用户状态可以写入和读取云数据库。
