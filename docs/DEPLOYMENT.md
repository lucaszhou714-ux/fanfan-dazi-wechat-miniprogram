# 体验版部署手册

## 前置条件

1. 注册微信小程序并取得 AppID。
2. 在微信公众平台添加开发成员和两名体验成员。
3. 安装微信开发者工具并开通云开发环境。

## 部署步骤

1. 用微信开发者工具导入项目根目录。
2. 将 `project.config.json` 中的 `appid` 替换为真实 AppID。
3. 在开发者工具中选择云开发环境，并将环境ID填写到 `miniprogram/config.js` 的 `envId`。
4. 右键 `cloudfunctions/login`，选择“上传并部署：云端安装依赖”。
5. 右键 `cloudfunctions/sync`，执行相同操作。
6. 在云开发数据库创建 `users`、`couple_spaces`、`couple_invites` 三个集合，权限全部设为仅云函数可读写。
7. 编译并在两部手机上预览关键流程。
8. 点击“上传”，在微信公众平台版本管理中将该版本设为体验版。
9. 两名体验成员扫码进入。

## 上线前检查

- 配置隐私保护指引。
- 确认服务类目、备案状态和用户协议。
- 检查云数据库权限，禁止客户端直接读取其他用户数据。
- 设置云资源用量告警和数据备份。
- 订阅消息需在公众平台选择模板后再配置模板ID。
